Bu yazılım, yorganın gecenin bir saatinde yatağın bir yakasından öteki yakasına kaymasını **uyku kazası** saymaz. Yorgan bir örtü değildir. Yorgan, sınırı geçen harekettir. Yastık karakoldur. Çarşaf geçiş belgesidir. "Biraz çekeyim gelir" cümlesi bu Başkanlık'ta **kaçak iade girişimi** kabul edilir.

Patates yoktur. Hava tahmini yoktur. Yorgan tahmin edilir; hava değil.

## Kurulum

Python 3.8+ yeter. Bağımlılık yoktur. Bağımlılık, yorganın sıcak tarafa olan doğal eğilimidir.

```bash
python3 goc.py
```

## Ne yapar?

1. Uyuyanın yatağındaki yakayı (sol / sağ / ortada-sürgün) kayda geçirir.
2. Yorganın kaç kez karşı tarafa göç ettiğini nüfus hareketi sayar.
3. Yastık sayısını sınır karakolu adedi kabul eder.
4. Oda sıcaklığını "itici unsur" olarak işler.
5. Karar üretir: ikamet, geçici koruma, iade, veya yere düşme (sınır dışı).
6. Resmî tutanak basar. Tutanak resmi görünür çünkü öyledir.
